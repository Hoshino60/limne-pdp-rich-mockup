2. 前提

  • テーマ：Impulse 6.0.1（2026年11月3日に公開中のテーマ「2026/10/27～　AutumnSALE終了」で確認）
  • 商品テンプレート：リッチコイル＝product.llmo_mattress_rich、エントリー＝product.llmo_entry（2026年11月3日の商品データで、それぞれの商品に割り当てられていることを確認）。ほかの商品が同じテンプレートを使っていないかは、テーマエディタでテンプレートを開いたときに出る、割り当て済みの商品の数で確かめる。2つ以上の商品に割り当てられていたら、直す前にご連絡ください
  • 「今の値」は2026年11月3日に公開中のページから取りました。その後にページを直している場合は、今の値が違うことがあります（違っていたら、直す前にご連絡ください）
  • テーマ（文・並び・スニペット・ブロック）の作業は、公開していないテーマ（今のテーマの複製）で行い、見本と見比べてから公開します
  • 「選ばれる理由」の段の画像の代替テキスト（alt）は、テーマではなく「コンテンツ」→「ファイル」の画像に付く情報で、変えるとすぐ公開中のページにも反映されます（テーマを複製しても分けられません）。テーマを公開するときに、あわせて変えてください（4章の代替テキストの節）

3. 手順の流れ

  1. テーマを複製する（「オンラインストア」→「テーマ」→ 公開中のテーマの「…」→「複製」）
  2. ファイルを3つ足す：複製したテーマの「…」→「コードを編集」で、snippets フォルダに limne-pdp-lead.liquid・limne-pdp-icons.liquid、sections フォルダに limne-pdp-closing.liquid を新しく作り（フォルダの「新しいファイルを追加」）、中身をこのフォルダの同じ名前のファイルの内容に置き換えて保存する。ファイルの書き方は Shopify の決まりに合わせています（スニペットは render で呼ぶ：https://shopify.dev/docs/api/liquid/tags/render 、CSSは {% stylesheet %}：https://shopify.dev/docs/api/liquid/tags/stylesheet 、セクションは {% schema %} の presets で「セクションを追加」に出し、enabled_on で商品ページだけに出す：https://shopify.dev/docs/storefronts/themes/architecture/sections/section-schema ）
  3. 複製したテーマの「カスタマイズ」（管理画面によっては「テーマを編集」）で、商品ごとに4章・5章のとおり直す（上のページ選択で「商品」→ テンプレート llmo_mattress_rich または llmo_entry）。プレビューに出す商品は、その商品（リッチコイル／エントリー）を選ぶ。直したら、右上の「保存」を押す
  4. 6章のとおり、複製したテーマのプレビューで見本と見比べ、購入の操作を確かめる
  5. ショッピングガイドの1文（2章の最後）を先方で直したことを確かめてから、複製したテーマを「公開」する。公開したら、すぐに画像の代替テキスト（4章の代替テキストの節）を変え、公開中のページで6章をもう一度確かめる
  6. 戻すときは、元のテーマ（公開前に公開していたテーマ）をもう一度「公開」し、代替テキストを、この手順書の「今」の値（空欄）に戻す
